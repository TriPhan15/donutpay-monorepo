Sao lưu dữ liệu OCR trên MongoDB

Sao lưu bằng mongodump thành file mongo_<thời gian>.archive.gz trong thư mục backups/. Phục hồi bằng mongorestore --drop từ bản mới nhất và chỉ ghi đè hai collection ocr_logs, ocr_feedbacks; các collection khác và PostgreSQL không bị ảnh hưởng. File lưu trữ chứa toàn bộ database finance_nosql, nhưng phục hồi chỉ thay thế ocr_logs và ocr_feedbacks.
